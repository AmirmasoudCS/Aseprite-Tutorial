# Aseprite-Tutorial

The tutorials I followed to learn `Aseprite` tool.

- [🍩 Doughnuts](./Doughnuts/)
Very simple shape drawing in `Aseprite` using different tools and getting to know the space of appliaction that you work with better. 
- [🐸 Frog](./Frog/)
Intorduction to character design and how to get reference for characters and what steps to follow in designing a character.
- [Animating the Frog](./Animating_the_Frog/)
Animating the `Frog` I designed in the previos section and getting to know the process of animating a character better and how to think about the stages of character movement/animation.
- [Canvas](./Canvas/)
Introduction to imagining a canvas, color selecting, tool selecting, how to make the user/player understand which sections they have access to and which they don't by pure design principles namely brightness, contrast, and shadowin. Basics of shadowing and how to add the illusion of depth and z-index in a 2D canvas.
